# 🚀 Swagger 自动文档

## 一条命令，自动生成

```bash
npm run swagger
```

就这么简单！无需手写任何注释。

## 使用流程

### 1. 编写接口（添加简单标签）

```javascript
router.post('/addUser', async (req, res) => {
  // #swagger.tags = ['用户管理']
  // #swagger.summary = '添加用户'
  
  // 你的业务逻辑
  res.json({ success: true, data: {}, message: '添加成功' });
});
```

只需两行注释，文档自动生成并分类！

### 2. 生成文档

```bash
npm run swagger
```

### 3. 查看文档

访问：http://localhost:8080/api-docs

## 优势

✅ **零学习成本** - 不需要学习 Swagger 语法
✅ **零维护成本** - 一条命令自动更新
✅ **代码即文档** - 永远同步，不会过期

## 自动化（可选）

如果希望每次启动时自动生成文档，修改 `package.json`：

```json
"dev": "npm run swagger && nodemon src/index.js"
```

## 自定义配置

编辑 `swagger-autogen.js` 可以调整：
- 标题、描述
- 数据模型示例
- 标签分组

修改后重新运行 `npm run swagger`。
